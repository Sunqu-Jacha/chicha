# Chicha · Mapa de Emprendimiento — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir el sitio estático Chicha (directorio filtrable, convocatorias, capa internacional, formularios moderados) y su backend en Google Sheets + Apps Script.

**Architecture:** Sitio de una sola página en HTML/CSS/JS sin framework (módulos ES), enrutado por hash, publicado en GitHub Pages. La lógica (filtros, rutas, estado de convocatorias, carga de datos, validación) vive en módulos puros probados con `node --test`; las vistas generan HTML escapado a partir de esos módulos. Un Apps Script vinculado a la hoja expone `doGet` (datos aprobados, columnas públicas) y `doPost` (envíos), y envía correos con MailApp; su lógica pura vive en `Logica.gs`, que también se prueba en Node.

**Tech Stack:** HTML5, CSS (custom properties), JavaScript ES2022 módulos, Node 24 (`node --test`, solo para pruebas), Google Apps Script (V8), Google Sheets, GitHub Pages, Google Fonts (Bebas Neue, Work Sans), íconos SVG de Tabler.

**Spec:** `docs/superpowers/specs/2026-11-04-chicha-design.md`

## Global Constraints

- Sin frameworks ni paso de compilación; el sitio funciona sirviendo la carpeta tal cual. Node solo para pruebas (sin dependencias de npm).
- Todo el texto de interfaz en español, sentence case salvo titulares en Bebas Neue (mayúsculas).
- Multivalores en la hoja separados por `;`. `descripcion` ≤ 280 caracteres.
- Zona horaria de referencia: `America/Lima`. Fechas como `AAAA-MM-DD`.
- "Cierra en N días" cuando faltan ≤ 14 días. Tiempo mínimo de llenado de formulario: 4 s. Caché del script: 600 s.
- Lógica de filtros: OR dentro del grupo, AND entre grupos.
- Colores: rojo `#C8232C`, negro `#141414`, blanco `#FFFFFF`; franja awayo `#C8232C #F28C28 #F6C700 #1E9E5A #1F6FB2 #6B3FA0 #D6246E #141414`; tonos de sector según tabla de la sección 5 del spec.
- Accesibilidad: contraste texto ≥ 4.5:1, foco visible, teclado completo, objetivos táctiles ≥ 44 px, texto base 16 px, `prefers-reduced-motion` respetado, sin emojis como íconos.
- Todo dato venido de la hoja se inserta en el DOM escapado (`esc`) — nunca `innerHTML` con datos crudos.
- Columnas privadas (`nombre_proponente`, `email_proponente`, `notas_moderacion`, `motivo_rechazo`) jamás salen del script: lista blanca de columnas públicas.
- Commits con la identidad local ya configurada en el repo y la línea `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Datos con HTML o `<script>` en nombre/descripcion** (llegan de un formulario público): deben mostrarse como texto literal → prueba de `esc` en Task 1 y de tarjeta escapada en Task 9.
2. **Búsqueda sin tildes ni mayúsculas** ("musica cusco" debe encontrar "Música" en "Cusco") → prueba en Task 2.
3. **Celdas multivalor desprolijas** (`"Música; ;Artes visuales "`) deben dar `["Música","Artes visuales"]` → prueba en Task 6.
4. **Fechas de la hoja como objeto `Date` o con desfase horario** (una fecha que aparece un día antes): normalizar a `AAAA-MM-DD` en Lima; `hoyLima` correcto cerca de la medianoche UTC → pruebas en Task 4 y Task 6.
5. **Enlaces compartidos viejos** (slug que ya no existe, id de agente archivado): la ruta se abre igual ignorando lo desconocido; la ficha muestra "Este agente ya no está disponible" → pruebas en Task 3 y verificación en Task 10.

### Task 2: Filtros de agentes

**Files:** Create `assets/js/filtros.js`, `tests/filtros.test.js`

**Interfaces:**
- Consumes: `normalizar`, `slug` (Task 1).
- Produces:
  - Tipo `Agente` = objeto de `agentes[]` del spec §7.1 (camelCase: `id, capa, nombre, descripcion, ofrece[], sectores[], tipoEntidad, presencia, pais, departamento, ciudad, direccion, lat, lng, web, instagram, facebook, otrasRedes, emailPublico, logoUrl, verificado, fechaAprobacion`).
  - Tipo `Criterios` = `{ q: string, ofrece: string[], sectores: string[], tipos: string[], departamentos: string[], presencia: string[] }` — los arreglos contienen **slugs**.
  - `criteriosVacios() -> Criterios`
  - `filtrarAgentes(agentes: Agente[], c: Criterios) -> Agente[]` — grupo vacío = sin restricción; dentro del grupo basta un valor (comparando `slug(valor)`); todos los grupos no vacíos deben cumplirse; `q` se separa en palabras normalizadas y **cada** palabra debe aparecer en `normalizar(nombre + descripcion + ciudad + departamento)`.
  - `ordenarAgentes(agentes, modo: 'az'|'recientes') -> Agente[]` — `az` con `localeCompare(…, 'es')`; `recientes` por `fechaAprobacion` desc, sin fecha al final. No muta la entrada.
  - `contarPorValor(agentes, campo: 'ofrece'|'sectores'|'tipoEntidad'|'departamento'|'presencia') -> Map<slug, number>`

  - `OR dentro de grupo`: ofrece `[financiamiento-y-fondos, formacion]` → A, B, C.
  - `AND entre grupos`: ofrece `[financiamiento-y-fondos]` + departamentos `[cusco]` → A.
  - `criterios vacíos devuelven todo`.
  - `búsqueda sin tildes`: `q: 'musica cusco'` → A (Review Focus 2).
  - `ordenar az usa reglas del español` (`"Ñandú"` después de `"Nazca"`) y `recientes sin fecha al final`; la entrada no se muta.
